# 兴业科技 `002674.SZ` 案例

## 结论

兴业科技这波更像是：

**旧标签公司被新能源车内饰供应链重估 + 事件后平台整理 + 5月13日放量首阳启动。**

公开数据不能充分证明 5月13日已经有强主力大规模净流入，但可以看到明显的量价启动痕迹。因此这个案例不应简单归因为“主力提前埋伏”，而应抽象成可验证策略：

**兴业科技型重估埋伏启动策略。**

## 时间线

- 2026-04-28：公司举行投资者电话交流会。
- 2026-05-06：披露投资者活动记录，参与机构包括多家券商、公募和私募。
- 2026-05-13：股价涨 4.09%，成交量 67102 手，约为此前 5 个交易日均量 1.87 倍。
- 2026-05-20：成交额显著放大，收盘 14.51，进入突破确认。
- 2026-05-25：触及 15.97 涨停价。

## 公开信息线索

投资者活动记录显示，公司汽车内饰皮革业务进入理想、蔚来、江淮尊界等供应链，并将其称为核心增长引擎。

这意味着市场可能从“传统皮革制造”切换到“新能源车内饰供应链”叙事。

## 量价线索

5月13日不是涨停，也不是行情最高潮，却满足启动特征：

- 收盘涨幅 4.09%
- 成交量明显高于此前数日
- 股价从整理区间向上离开
- 后续 5月20日出现进一步放量确认

## 主力提前介入判断

谨慎结论：

- 有资金启动痕迹。
- 没有足够公开证据证明 5月13日强主力已经明显净流入。
- 涨停当天 5月25日超大单流入更明显，但那已经是兑现阶段，不是提前发现阶段。

所以，策略要捕捉的是“涨停前的重估启动”，不是“涨停当天的资金异动”。

## 可复制条件

候选股需要同时满足：

- 原标签传统，存在新业务重估可能；
- 调研或公告内容能映射到收入、利润率、订单、客户或产能；
- 调研披露后没有立刻连续暴涨；
- 出现第一根 3%-6% 放量中阳；
- 次日不破启动日中枢或后续继续放量承接；
- 止损位清晰。
