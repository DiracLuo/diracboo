# 策略库

## 1. 强趋势突破

寻找已经强于市场的股票，而不是低位幻想反转。

关键条件：

- 价格突破中期平台或接近新高
- 成交量大于 20 日均量 1.5 倍
- 相对强度强于指数
- 不追连续高潮

## 2. 财报后动量

财报超预期后，市场常常需要几天到几周重新定价。

关键条件：

- 营收、利润、毛利率或指引超预期
- 财报后不跌破关键价位
- 机构上修或资金继续流入

## 3. 空头拥挤反转

适合美股。高空头股票在利空出尽后可能出现快速回补。

关键条件：

- 空头比例高
- 基本面或融资风险改善
- 放量收复关键均线

## 4. 港股低估值修复

适合港股的中期波段。

关键条件：

- 估值低于历史或同业
- 基本面边际改善
- 南向资金或板块成交改善

## 5. 港股互联网龙头趋势恢复

适合腾讯、阿里、美团、小米等龙头。

关键条件：

- 站上 20/60 日均线
- 业绩、回购、产品周期或政策改善
- 南向资金和成交额同步改善

## 6. 中小盘异常放量异动

寻找低关注度股票的提前异动。

关键条件：

- 中小市值且流动性足够
- 成交量突然放大
- 有公告、订单、调研、行业主题或产品事件
- 尚未连续涨停或情绪高潮

## 7. 兴业科技型重估埋伏启动

这是从兴业科技案例抽象出的统一策略，不再拆成“机构调研后重估首阳”和“事件埋伏启动”两条。

核心思想：

兴业科技真正给我们的启示是：一个旧标签公司出现可验证的新增长叙事，市场没有在事件披露日立刻高潮，而是先在平台内整理吸筹，再通过放量首阳或临界突破启动。这里的重点不是“有调研”本身，而是调研/公告是否能把公司从旧估值框架切换到新估值框架。

关键条件：

- 近 25 个自然日有调研、订单、合同、客户、产能、产品、海外、利润率或业绩类事件
- 事件必须能映射到订单、客户、产能、利润、产品结构或业务标签切换
- 排除单纯业绩说明会预告、普通担保、普通授信、法律意见书、常规股东会等弱事件
- 事件后没有连续高潮，而是在短期平台内整理，10 日平台振幅不能过大
- 启动前 5-10 日成交量温和抬升，红盘天数不弱，但不能单日爆量高潮
- 当日出现 2.5%-8.5% 放量阳线
- 接近 10 日高点或 20 日高位区
- 排除 ST / 退市风险名称

退出规则：

- 跌破启动日低点或事件前平台下沿，视为失败
- 达到 7%-16% 目标后分批
- 首次触发只进入观察，次日不破启动日中枢或继续放量承接才升级
